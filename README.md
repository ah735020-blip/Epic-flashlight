# Flashlight App

A simple Android flashlight app using the phone's camera flash.

## Features
- White flashlight logo
- Dark modern interface
- Tap the center torch to turn the flashlight ON/OFF
- Developer name: ARMAN
- Android 6.0+ compatible (API 23+)

## Build APK from a phone with GitHub Actions
1. Create/sign in to a GitHub account.
2. Create a new repository (for example: FlashlightApp).
3. Upload all files and folders from this project, including `.github/workflows/build-apk.yml`.
4. Open the repository's **Actions** tab.
5. Select **Build Flashlight APK**.
6. Tap **Run workflow**.
7. After it finishes, open the completed workflow run.
8. Under **Artifacts**, download **Flashlight-ARMAN-APK**.
9. Extract the downloaded artifact and install `app-debug.apk`.

If GitHub shows a workflow permissions prompt, allow Actions to run for the repository.
